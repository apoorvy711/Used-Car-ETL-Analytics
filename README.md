# 🚗 Used Car ETL & Analytics Pipeline

An end-to-end **ETL (Extract, Transform, Load) and Data Analytics project** built to analyze used car market data using Python, SQL, and data visualization techniques.

This project focuses on cleaning raw used-car datasets, transforming them into meaningful insights, and performing analytics to understand trends like pricing, fuel types, mileage, transmission preferences, and brand popularity.

---

# 📌 Project Overview

The goal of this project is to simulate a real-world **data engineering + analytics workflow** by:

- Extracting raw used car data
- Cleaning and transforming messy datasets
- Performing exploratory data analysis (EDA)
- Generating business insights
- Building an organized ETL pipeline

This project demonstrates practical skills in:

- Data Cleaning
- ETL Pipelines
- Data Analysis
- Data Visualization
- Python Automation
- SQL Queries

# ⚙️ ETL Pipeline Workflow

## 1️⃣ Extract
- Imported raw used-car dataset
- Loaded CSV data using Pandas
- Inspected missing values and duplicates

## 2️⃣ Transform
- Cleaned null values
- Removed duplicates
- Standardized column formats
- Converted datatypes
- Handled outliers
- Prepared data for analysis

## 3️⃣ Load
- Stored cleaned dataset
- Generated analytics-ready data
- Exported transformed files for visualization

# 🚀 How to Run the Project

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/apoorvy711/Used-Car-ETL-Analytics.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd Used-Car-ETL-Analytics
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run the Scripts

```bash
python extract.py
python transform.py
python load.py
```
